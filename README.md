# Audio Subtitle Translator

Приложение для перевода речи в реальном времени. Захватывает звук с микрофона, распознает русский текст и переводит его на английский.

## Возможности

- 🎤 Захват звука в реальном времени
- 🗣️ Распознавание русской речи (OpenAI Whisper)
- 🌍 Перевод русского текста на английский (Google Translate)
- 📺 Оверлей с субтитрами на рабочий стол

## Требования

- Python 3.8+
- Микрофон или системный звук
- Интернет для Google Translate API (опционально)

## Установка

```bash
# Установить зависимости
pip install -r requirements.txt

# Создать .env файл (опционально)
cp .env.example .env
```

### Для лучшего перевода (опционально)

1. Создать Google Cloud Project: https://console.cloud.google.com
2. Включить Translation API
3. Скачать JSON ключ и сохранить его
4. Указать путь в `.env`:
```
GOOGLE_APPLICATION_CREDENTIALS=/path/to/your/google-credentials.json
```

## Запуск

```bash
python main.py
```

## Использование

1. Запустить приложение
2. Говорить в микрофон на русском языке
3. Субтитры будут отображаться в окне:
   - **Синий текст** - оригинальный русский текст
   - **Зеленый текст** - перевод на английский

## Архитектура

- `src/audio_capture.py` - захват звука с микрофона
- `src/speech_to_text.py` - распознавание речи (Whisper)
- `src/translator.py` - перевод текста (Google Translate)
- `src/ui.py` - пользовательский интерфейс (Tkinter)
- `main.py` - главная программа

## Проблемы и решения

### Нет звука
- Проверьте, что микрофон подключен и активен
- Используйте `python -m sounddevice` для проверки доступных устройств

### Модель Whisper очень медленная
- Используйте меньшую модель: измените `model_size="tiny"` в main.py
- Размеры: tiny < base < small < medium < large

### Перевод не работает
- Если нет Google Cloud ключей, используется локальный fallback (deep-translator)
- Проверьте интернет соединение
